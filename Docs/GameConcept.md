# 게임 콘셉트 — 이끼송곳니 거점

2026-11-06 기준. 사용자 방향, 현재 프로토타입 구현, 향후 제안을 구분한다.

## 사용자가 정한 방향

- 고블린이 인간을 노예로 확보하고 교육·육성하여 판매하거나 활용하는 경영 게임이다.
- 원정의 비중을 최소화하고 주인공 일행만 원정을 담당한다. 포획 인원은 거점에서 육성하며 원정대에 편성하지 않는다.
- 육성 인원의 활용처는 검투·경기·대회와 공연·흥행 운영이다. 사용자가 말한 '놀이'는 이 두 활동을 뜻한다.
- 화면은 2D 횡스크롤 방향을 유지한다. 거점 시설과 생활·교육을 기본 화면으로 삼는다.
- 이번에는 캐릭터의 종족별 그림 교체와 추가 단순화를 뒤로 미루고, 육성 기능과 배경·화면 디자인을 먼저 만든다.

## 현재 구현한 육성 순환

**인원 확보 → 적성 확인 → 교육·휴식 → 경기·공연 또는 판매 → 시설 확장.**

`Prototype/management-core.mjs`에 새 거점 규칙을 구현했다. 현재 수치와 일정은 프로토타입을 실행하기 위한 설정이며 최종 경제 밸런스가 아니다. 자세한 값은 [RaisingManagement.md](RaisingManagement.md)에 기록한다.

- 시작 상태: 120 G, 육성 인원 루카·에린 2명, 숙소 6명, 교육 자리 1개.
- 인물별 수치: 무예·예능 적성, 각 분야 숙련도, 컨디션, 경기 승리·공연 실적.
- 교육: 무예 또는 예능을 선택하고 비용과 시간을 사용한다. 적성이 좋은 분야는 더 빠르게 성장한다. 교육 결과가 판매 예상가에 반영된다.
- 휴식: 비용 없이 컨디션을 회복한다. 컨디션이 부족하면 교육·활동에 참가할 수 없다.
- 활용: 초급 경기와 천막 공연에 배치해 시간 완료 후 수입·실적을 얻는다. 한 인물은 한 일정만 수행하고, 경기장과 공연장은 각각 한 자리다.
- 판매: 일정이 없는 인물을 현재 가격에 판매한다. 골드를 받고 명단에서 빠지며 같은 인물을 다시 판매할 수 없다.
- 시설: 숙소 정원과 동시 교육 자리를 골드로 확장한다.
- 원정: 그릭·보루·녹의 고정 고블린 일행이 18초간 파견되어 인간 한 명을 확보한다. 육성 인원과 별도 명단이며 원정 중에도 거점 일정은 계속된다.
- 저장: 버전 2의 별도 저장 키를 사용한다. 진행 중 교육·활동·원정도 남은 진행 상태를 복원하며 오프라인 보상은 계산하지 않는다. 이전 버전의 저장값은 그대로 남는다.

초급 경기는 무예 조건을 충족한 뒤 정해진 시간이 지나면 승리·보상을 받는 활동이다. 실제 적과의 대전·패배 판정을 구현한 것은 아니다. 공연도 단일 활동이며 장르·팀 편성·관객 수요는 아직 없다.

## 화면과 아트

이끼 낀 목책과 목조 시설, 훈련 마당과 천막 공연장이 이어지는 숲속 거점을 기본 공간으로 만든다. 캐릭터 선택과 교육·활동 배치가 원정 진행보다 먼저 보이도록 구성한다. 상세 방향은 [거점 화면 디자인](../VISUAL_DESIGN.md)과 [ArtDirection.md](ArtDirection.md)를 따른다.

현재 성인 모험가 도트와 일러스트 초상화는 임시로 재사용한다. 가제는 **이끼송곳니 거점**이며 정식 게임명과 출시용 엔진을 확정한 것은 아니다. 캐릭터의 추가 단순화와 고블린·인간별 고유 외형은 다음 아트 작업으로 남긴다.

규칙 자동 검사와 실제 화면 검수는 [ManagementValidation.md](ManagementValidation.md)에서 구분한다. 자동 테스트 통과만으로 장기 경제나 재미를 검증했다고 주장하지 않는다.

## 이전 원정 프로토타입 — 보관 기록

첫 버전의 가제는 **붉은 망토 원정대**였다. 걷기·공격 애니메이션과 횡스크롤 자동 전투를 검증하기 위해 제작했다.

- 안개 숲길·무너진 성문·잿빛 왕도의 세 난이도, 원정당 전투 두 번과 포획 최대 두 명.
- 포획 인원을 노동 또는 원정 동행에 배치했고, 대장을 즉시 훈련할 수 있었다.
- 귀환 시 포획·골드를 한 번 정산했다. 진행 중 원정은 저장하지 않았다.
- 이 버전의 핵심 규칙과 자동 테스트는 `Prototype/game-core.mjs`, `Prototype/tests/game-core.test.mjs`에 남겨 둔다.

사용자의 수정에 따라 **포획 인원의 원정 동행, 대장 훈련 중심 성장, 원정이 큰 기본 화면**을 새 버전의 중심에서 제외했다. 기존 걷기·공격 자산과 제작 기록은 재사용한다.

## 이후 결정할 사항

- 경기의 실제 상대·승패·대회 구조, 공연의 장르·팀 구성.
- 구매자별 수요와 계약, 유지비, 교육·활동·판매의 장기 수익 균형.
- 주인공 일행의 고용·성장 범위와 원정 목적지 차이.
- 성격·관계·탈출 등 추가 시스템의 도입 여부.
- 정식 캐릭터 세트, 출시 플랫폼·엔진·게임명.

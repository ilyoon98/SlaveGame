# 아트 방향: 횡스크롤 원정 경영

## 최신 거점 화면 방향

2026-11-06 사용자 수정: 고블린이 인간을 확보하고 교육·경기·공연·판매로 운영하는 거점 육성이 중심이다. 이번 개편에서는 캐릭터 단순화와 종족별 새 외형을 미루고 기존 도트를 임시로 사용한다. 새 배경과 시설·육성 화면을 먼저 제작한다.

현재 거점 화면의 전체 지침은 [VISUAL_DESIGN.md](../VISUAL_DESIGN.md)를 따른다. 이끼 낀 숙소, 교육 마당, 작은 경기장, 천막 공연장과 거래소가 나란히 이어지는 [배경](../Assets/Environments/goblin-camp.png)을 새로 제작했다. 아래 기존 원정 표현 지침은 캐릭터 자산과 애니메이션 제작 이력으로 남긴다.

**Concept-Derived Visual Tags**: `concept-derived: 옆모습 원정대`, `concept-derived: 큰 색면 판타지`, `concept-derived: 짧고 분명한 타격`

사용자가 정한 방향은 2D 횡스크롤, 자동 전투와 거점 경영, 기존 캐릭터의 그림체를 유지한 소폭 단순화다. 현재 브라우저 프로토타입에는 인게임 도트와 일러스트 초상화를 함께 적용했다. 아래의 초기 제안과 실제 적용값은 구분한다.

## 현재 적용한 자산 — 2026-11-06

- 원본: 단순화한 갈색 머리·붉은 망토 검사. 초상화는 동일 원본을 사용한다.
- `2dimg2motion`의 실제 포즈 생성 지침으로 걷기와 한손 전방 찌르기를 각각 14프레임 제작했다. `Codixel`로 공통 24색 팔레트를 적용하고 게임용 아틀라스로 묶었다.
- 프레임 캔버스는 **128×112px**, 공통 피벗은 **(64,100)**이다. 대기 자세의 실제 몸 높이는 약 69px이며, 넓은 캔버스는 찌르기 동작의 검과 망토를 담는 공간이다. 초기 정적 시안의 64×80 캔버스와 다르다.
- 대기 1장, 걷기 14장/980ms, 공격 14장/770ms. 시작·끝 프레임은 동일 원본이며 공격은 0.28초에 피해를 준다.
- 화면 왼쪽의 은색 어깨갑옷 팔은 빈손, 반대쪽 팔은 검을 유지한다. 배경의 흐린 알파 잔색을 제거하고 투명/불투명 두 단계로 내보냈다.
- PixelFX의 찌르기와 속박 효과를 사용한다. 포획은 속박·채도 변화·귀환 대열로 표시하며, 별도의 무기 내림 포즈는 아직 없다.
- 적과 동행 인원은 동일 검사 도트의 색상 변형이다. 고유 직업 외형과 직업별 동작은 다음 제작 범위다.

실제 게임에서 이동·전투·포획·귀환을 확인했고, 별도 재생 화면에서 프레임 정지와 타격 자세를 확인했다. 프레임 검증 통과가 수작업 애니메이션 수준의 자연스러움을 보장하지는 않는다. 걷기 리듬, 세부 실루엣의 흔들림, 지면 이동과 접지의 정밀한 일치는 추가 다듬기 대상이다.

## 1. Visual Concept

**붉은 망토와 검의 실루엣이 먼저 읽히는, 단정한 판타지 원정대.**

원정에서는 부대가 옆으로 이동하며 모험가와 자동으로 싸운다. 조작의 중심은 편성·노동·훈련·투자에 두고, 횡스크롤 표현만으로 점프 조작이나 플랫폼 액션을 추가하지 않는다.

화면의 주인공은 선택한 아군 전투원, 주된 위험은 그 전투원과 대치하는 적, 주된 보상은 살아서 귀환하는 포획 인원이다. 이 셋의 구분이 배경 장식보다 먼저 성립해야 한다.

| 의상과 중간 면 | 남색 `#344760` | 검사 튜닉과 작업복의 큰 연결된 색면 |
| 캐릭터 표식·위험 강조 | 적갈색 `#B64E45` | 붉은 망토의 정체성, 짧은 위험 표시. 둘은 위치와 형태로 구분 |
| 금속과 순간 피드백 | 은회색 `#C4CED4` | 검날·어깨갑옷, 짧은 피격 섬광 |
| 보상과 완료 | 황금색 `#D5AF59` | 골드 획득, 포획·귀환 완료에만 제한적으로 강조 |

## 3. Object Rendering Specifications

### 검사 단순화

- 유지: 갈색 머리, 붉은 망토 또는 스카프, 남색 튜닉, 검, 은색 어깨갑옷. 성인 모험가의 비례와 기존 판타지 그림체를 유지한다.
- 머리: 잔머리 대신 큰 덩어리 3~4개로 정리한다.
- 망토: 큰 면 하나와 목 부근 접힘 정도로 줄인다. 여러 갈래 천 조각과 잘게 찢어진 끝을 없앤다.
- 갑옷: 어깨 한 면과 간단한 팔 보호구 중심으로 정리한다. 리벳·장식 문양·겹겹의 작은 금속판을 생략한다.
- 허리: 단순한 띠 하나를 남기고 작은 버클, 파우치, 가슴을 가로지르는 중복 끈을 제거한다.
- 검: 손잡이와 검날이 분리되어 읽히도록 한다. 장식보다 무기의 길이와 공격 방향을 우선한다.
- 초상화: 같은 의상 구조를 사용하고 눈·표정·재질에서만 정보를 더한다. 도트에 없는 장비를 초상화에 계속 추가하지 않는다.

### 인게임 규격 후보

- 기본 캐릭터 캔버스는 **64×80px 후보**. 최초 48×64 변환에서 얼굴 정보가 많이 줄어 이번 정적 미리보기는 64×80으로 조정했다. 오른쪽을 보는 옆모습으로 시작하고 모든 동작에서 발 기준점을 공유한다.
- 공격 중 검이 잘리면 전 동작의 공통 캔버스를 넓히거나 무기·타격 효과를 별도 레이어로 둔다. 캐릭터를 프레임마다 축소해 끼워 넣지 않는다.
- 몸통·머리·가까운 팔과 검·먼 팔·양다리·망토 정도로 레이어를 나눈다. 장식마다 별도 관절을 만들지 않는다.
- 또렷한 픽셀 경계와 일정한 광원을 사용한다. 실사용 표시 크기에서 검사한 뒤 정수 배율로 확대한다.
- 왼쪽 보기용 반전은 초기 후보로 허용하되, 장비의 좌우 의미나 비대칭 공격 판정이 생기면 별도 방향 작업을 검토한다.

### 작은 화면에서의 판독성

검사 1명의 검·머리·망토를 검은 실루엣으로 구분할 수 있어야 한다. 실제 표시 크기에서 아군 세 명과 적이 겹쳐도 각자의 머리와 공격 방향이 읽혀야 한다. 아군은 왼쪽에서 오른쪽을 보고 전진하는 기본 구도, 적은 반대 구도로 배치하며 발밑 형태와 선택 표식을 함께 사용한다. 붉은 망토 자체를 적 표식으로 쓰지 않는다.

## 4. Background & Environment

- 원경은 낮은 대비, 지면은 발 위치를 읽을 수 있는 단순한 면, 전투원은 가장 또렷한 대비로 나눈다.
- 느린 원경과 빠른 근경의 시차 이동으로 횡스크롤을 표현하되, 장식물이 검과 발을 가리지 않게 한다.
- 충돌 지점의 중앙에는 배경의 밝은 점·가지·표지판을 모으지 않는다. 상세 일러스트는 전투 영역과 분리한 정보창에서 보여준다.
- 거점에서는 노동 장소와 훈련 장소의 도구·동작을 다르게 해 배치 상태를 보여준다. 반복 움직임은 작게 유지한다.

## 5. Feedback Effects

| 사건 | 화면 반응 | 기준 |
| --- | --- | --- |
| 이동 | 발 교대와 작은 상체 흔들림, 망토의 늦은 따라 움직임 | 지면 접촉과 이동 속도 일치 |
| 공격 | 준비 → 타격 → 회수, 짧은 검 궤적 | 준비 없이 번쩍이는 효과만 내지 않음 |
| 피격 | 순간 밝기 변화와 작은 뒤로 젖힘 | 아군·적 모두 같은 문법, 지속 점멸 방지 |
| 승리·포획 | 적이 무기를 내리고 전투 자세를 풀며 귀환 대열로 이동 | 포획을 소멸·사망과 구분, 정산 시점을 반영 |
| 골드 정산 | 작은 황금색 획득 효과를 골드 표시 쪽으로 이동 | 아직 귀환하지 않은 보상을 미리 지급한 것처럼 표현하지 않음 |
| 훈련 완료 | 연습 동작을 멈추고 짧은 준비 자세 | 상시 빛기둥이나 긴 축하 연출을 사용하지 않음 |

## 6. Relationship with Visual Tags

- 옆모습 원정대: 이동·대치 방향과 발 기준선을 통해 역할과 진행을 읽게 한다.
- 큰 색면 판타지: 머리·망토·무기를 남기고 작은 장식을 덜어 동일 인물을 도트와 초상화에서 연결한다.
- 짧고 분명한 타격: 타격의 준비와 회수에 시간을 배분하고, 섬광과 파티클은 동작을 보조한다.

## 7. AI-Generated Look Suppression Rules

### 7.1 Visual Hierarchy Rules

- Protagonist: 선택한 아군 전투원. 발밑 선택 형태와 진행 방향으로 찾을 수 있게 한다.
- Threat: 대치 중인 적. 반대 자세와 공격 준비 동작으로 위험을 드러낸다.
- Reward: 포획 후 귀환 대열에 합류하는 모험가와 귀환 시 발생하는 골드 효과.
- 2-second recognition check: HUD 글자를 가린 전투 정지 화면에서 처음 보는 사람이 아군, 적, 공격 방향을 찾는지 확인한다. 포획 전후 화면에서도 인원 상태 변화가 읽히는지 별도로 확인한다. 아직 검증하지 않았다.

### 7.2 Limits on Familiar Template Symbols

- Adopted familiar elements (max 2): 체력 막대, 골드 동전 표식.
- Replaced unique element: 무의미한 보상 상자 연출 대신 포획된 인원이 귀환 대열에 합류하는 모습으로 핵심 보상을 보여준다.

### 7.3 UI-Independent Feedback

| Event | Non-UI visual response | Intensity (Low/Med/High) |
| :---- | :--------------------- | :----------------------- |
| Score | 귀환 정산 때 짧은 금색 획득 효과 | Low |
| Damage | 피격 자세와 짧은 은회색 섬광 | Med |
| Near miss | 첫 버전에는 별도 회피·아슬아슬한 판정이 없으므로 연출 추가 안 함 | Low |
| Capture | 무기 내림, 전투 자세 해제, 귀환 대열 합류 | Med |

### 7.4 Composition and Gaze Guidance

- Initial focal point: 아군 선두와 현재 대치하는 적 사이의 공간.
- Visual flow: 아군 편성 → 진행 방향 → 상대의 준비 동작 → 타격 → 포획·귀환.
- Anti-center-clutter implementation: 중앙의 장식 대비를 낮추고, 중복 피해 숫자와 큰 초상화를 전투 실루엣 위에 겹치지 않는다.

## 8. 제작 전달과 검수

**먼저 제작할 것:** 검사 1명의 도트 원본, 동일 의상의 초상화, 대기 2~4프레임·걷기 4~6프레임·공격 4~6프레임 후보. 실루엣과 핵심 자세를 확인한 뒤 중간 프레임을 추가한다. 정적인 비교 시안은 애니메이션 품질의 증거로 사용하지 않는다.

**이미지 자산:** 캐릭터, 초상화, 지형 타일, 검 궤적의 모양. **코드로 처리할 것:** 카메라·시차 이동, 선택 표식, 체력 막대, 짧은 색상 변화와 작은 파티클, 결과 정산 표시. 첫 프로토타입은 HTML Canvas이며 출시용 엔진은 아직 정하지 않았다.

검수 항목:

- [ ] 원본 크기와 실제 화면 크기 모두에서 머리·망토·검이 읽힌다.
- [ ] 도트와 초상화의 머리색·복색·장비 구성이 같다.
- [ ] 프레임마다 머리 크기, 팔다리 길이, 검 길이와 광원이 불필요하게 바뀌지 않는다.
- [ ] 정지된 발이 지면에서 미끄러지지 않고, 걷기의 접지와 이동 속도가 맞는다.
- [ ] 손과 검이 연결되고 망토가 팔과 검을 지속적으로 가리지 않는다.
- [ ] 공격에 준비·타격·회수가 있고 타격 판정과 시각적 접촉 시점이 맞는다.
- [ ] 루프 시작과 끝이 튀지 않는다. 프레임 나열 검사와 실제 반복 재생을 모두 수행한다.
- [ ] 투명 배경에 테두리 잔색이 없고, 프레임·기준점·재생 시간이 출력 메타데이터와 맞는다.
- [ ] HUD를 가린 판독성 검사와 실제 배경 위 다인 전투 검사를 통과한다.

현재 상태: 상단의 적용 자산과 브라우저 프로토타입을 제작했다. 위 목록은 정식 아트 승인용 목표로 유지하며, 수행한 검사와 남은 범위는 [프로토타입 검증 기록](PrototypeValidation.md)에 구분한다.

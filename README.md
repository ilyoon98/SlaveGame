# 이끼송곳니 거점

[프로젝트 저장소](https://github.com/ilyoon98/SlaveGame)

고블린 일행이 확보한 인간 노예를 거점에서 교육하고, 경기·공연에 배치하거나 판매하는 **브라우저 육성 경영 프로토타입**이다. 원정은 고블린 주인공 일행만 담당하며, 육성 인원은 거점을 떠나는 원정대에 편성되지 않는다.

## 실행

프로젝트 폴더에서 별도 패키지 설치 없이 실행한다.

```powershell
node Prototype/server.mjs
```

[게임 열기](http://127.0.0.1:4173/Prototype/). 서버를 실행한 터미널을 유지하고 종료할 때 `Ctrl+C`를 누른다. `index.html`을 직접 열지 말고 서버 주소를 사용한다. 이미 서버가 실행 중이면 같은 주소를 열면 된다. 서버는 `127.0.0.1`에만 연결된다.

PowerShell 런처는 `.\Prototype\Start-Prototype.ps1`이다. 스크립트 실행이 제한되면 정책 변경 없이 위의 `node` 명령으로 실행한다.

## 플레이

시작 자금은 **120 G**, 육성 인원은 **루카·에린 2명**, 숙소 정원은 **6명**, 동시 교육 자리는 **1개**다.

왼쪽 목록에서 인물을 고르고, 오른쪽의 **교육 · 활동 · 휴식**에서 일정을 선택한다. 상세 능력은 **인물 정보**, 원정과 확장은 아래의 **원정 · 시설 관리**를 펼쳐 확인한다. 진행 기록도 기본적으로 접혀 있다.

1. 인물을 선택해 무예·예능 적성과 숙련도, 컨디션, 판매 예상가를 확인한다.
2. **무예 교육** 또는 **예능 교육**에 8 G를 사용한다. 10초 후 적성에 따라 숙련도와 판매 가치가 오른다.
3. **초급 경기**는 무예 3 이상, **천막 공연**은 예능 3 이상일 때 참여할 수 있다. 각각 12초 후 숙련도·실적에 따른 수입을 받는다.
4. 교육과 활동으로 줄어든 컨디션은 **숙소 휴식**으로 회복한다. 8초 휴식은 무료이며 컨디션을 최대 40 회복한다.
5. 인물을 계속 키우거나 **판매**해 자금과 수용 공간을 확보한다. 일정 중에는 판매할 수 없다.
6. **숙소 확장**으로 정원을 2명씩, **교육실 확장**으로 동시 교육 자리를 1개씩 늘린다.

교육·휴식·경기·공연 중 한 인물은 한 일정만 수행한다. 경기장과 공연장은 각각 한 명씩 사용할 수 있다. 일정 중단 시 이미 사용한 비용과 컨디션은 환불되지 않는다. 일시정지와 1배·2배속은 거점 일정과 원정에 함께 적용된다.

작은 원정 패널에서 **고블린 일행을 파견**하면 18초 후 인간 한 명을 확보한다. 그릭·보루·녹의 고정 일행만 출발하며, 거점 교육은 계속 진행된다. 출정은 무료이고 숙소가 가득 차면 새 원정을 시작할 수 없다.

## 저장과 구현 범위

골드·인원·숙련도·컨디션·시설뿐 아니라 **진행 중인 일정과 원정의 남은 진행 상태**를 자동 저장한다. 새로고침 후 이어서 진행하며 오프라인 시간은 계산하지 않는다. 새 버전 2 저장 키를 사용하므로 이전 원정 프로토타입의 저장값은 덮어쓰지 않는다. 저장은 브라우저와 주소별로 분리된다.

초급 경기는 참가 조건을 충족한 인물이 정해진 시간을 마치면 승리하는 활동이다. 실제 상대와의 대전·패배 판정은 아직 없다. 공연도 시간 완료와 숙련도에 따른 수입을 검증하는 단일 활동이다. 복잡한 대회, 공연 팀 구성, 구매자별 수요, 장기 경제 조정은 이후 범위다.

배경은 숲속 고블린 거점으로 새로 제작했다. 사용자가 캐릭터 교체와 추가 단순화를 뒤로 미뤘으므로, 현재 성인 모험가의 도트·초상화 자산을 임시로 재사용한다. 고블린 전용 캐릭터 세트를 완성한 것은 아니다.

## 검증과 제작 도구

새 육성 규칙의 통합 테스트:

```powershell
node --test Prototype/tests/management-core.test.mjs
```

이전 원정 규칙과 테스트는 `Prototype/game-core.mjs`, `Prototype/tests/game-core.test.mjs`에 보관한다. 새 거점 규칙은 `Prototype/management-core.mjs`다. 자동 규칙 검증과 브라우저 시각 검수 결과는 검증 문서에서 구분한다.

게임 실행에는 Node.js만 필요하다. 리소스 제작용 Python은 프로젝트 `Tools/.venv`에 분리되어 있다. `build-character-preview.cjs`는 설치된 Codixel 스킬을 사용하며, 제작 도구의 설치 상태는 스킬 문서에 기록한다. PixelOE의 실행 의존성은 아직 설치하지 않았고, Sprite Sheet Diffusion은 포함된 OpenPose의 비상업 연구용 제한 때문에 제작에 사용하지 않는다.

거점 배경의 생성 경로는 내장 `image_gen` (`host_image`)이며, `generate2dmap`으로 장면 데이터, 화면 크롭, 시설 보존과 실제 캐릭터의 발 위치를 추가 검증했다. 가상환경, 내려받은 외부 도구 저장소, 로컬 서버 로그와 머신 진단 원본은 Git에서 제외한다.
